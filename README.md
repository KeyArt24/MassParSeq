# MassParSeq
Programm for Quality Analysis NGS library
=======
**Massparseq EDAQ**
Программа для анализа качества библиотек массового параллельного секвенирования. Предназначена для быстрой обработки больших объёмов данных fastq и сжатых .fastq.gz файлов. 

**Скорость и производительность**
В основе анализа лежит JIT-компиляция Python-кода (Numba). Критические участки парсинга компилируются в машинный код непосредственно перед выполнением, что даёт производительность, сопоставимую с C/C++.
чтение файлов через mmap — без полной загрузки в память; 
обработка блоками по 512 МБ; 
распараллеливание на все ядра CPU; 
работа со сжатыми .gz без распаковки на диск. 

**Многопоточность****
**Анализ выполняется в отдельном потоке (QThread) и не блокирует интерфейс. Поддерживается очередь задач, прогресс в реальном времени и отмена анализа. 

**Функциональные возможности**
Распределение качества по нуклеотидам — Phred-оценки по позициям (медиана, среднее, квантили); 
Подсчёт количества ридов; 
Распределение GC-состава; 
Определение длины ридов — минимальная и максимальная; 
Нуклеотидный состав — доли A, C, G, T, N; 
Поиск неизвестных символов.
